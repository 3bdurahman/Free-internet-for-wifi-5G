# Free internet for 5G wifi
Bash script helps you get a free 5G Wi-Fi internet subscription
![free subscription](doc/Screenshot.png)
##  Installation
   ```sh
   sudo apt install arp-scan
   sudo apt install macchanger
  ```
---
##  USAGE
**NOTE1: This script only works with 5G wifi**
**NOTE2: If use Vmware Change Network to Bridge**
   ```sh
   git clone https://github.com/3bdurahman/Free-internet-for-wifi-5G.git
   cd Free-internet-for-wifi-5G/
   chmod 755 abdo_hashem.sh
   sudo bash abdo_hashem.sh
  ```
